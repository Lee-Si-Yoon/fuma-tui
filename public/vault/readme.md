## Welcome

This is your documentation site. Edit entries in `public/vault/` and they'll appear here automatically.

### Getting started

1. Edit `site.config.ts` to set your site name, accent color, and GitHub repo
2. Replace entries in `public/vault/` with your own
3. Run `pnpm dev` to preview
4. Push to Vercel — zero env vars needed
